Action Execution Reality Check

ZERO Deck Studio clearly differentiates between actions the pad can execute on its own versus actions requiring the companion desktop PC daemon:

Action Type Execution Location Requires Desktop App? Behavior
Keystrokes & Combos On-Device (RP2040) No Sends standard USB HID keystrokes natively. Works on any PC, Mac, or Linux machine without installing any software.
Consumer Media & Mute On-Device (RP2040) No Sends standard USB HID Consumer Usage codes (Play/Pause, Vol Up/Down, Mute).
App Launcher PC Daemon Yes Executes local application path (e.g. Photoshop, Discord, VS Code) on Windows.
WASAPI Per-App Volume PC Daemon Yes Adjusts specific process volume sliders in Windows Volume Mixer via C# COM interop.
OLED System Telemetry PC Daemon Yes Reads live CPU, GPU, and RAM usage from Windows and streams pixel chunks to the pad.
