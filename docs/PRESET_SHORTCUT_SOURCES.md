# Additional app preset shortcut references

These presets send the documented default shortcuts as single keyboard chords.
They assume the app or indicated editor/timeline is focused. Shortcuts can differ
by OS, version, keyboard layout, user keymap, and active context; browser or OS
shortcuts can also intercept a chord. No application is launched by a preset.

## Game presets

Game presets use keyboard bindings, not scripts or rapid-fire sequences. In the
updated Keys & Knob firmware, ordinary unflagged keyboard bindings follow the
physical switch: key-down when pressed, key-up on release. The OS controls text
repeat. The supplied Full Deck image has not been changed and its hold behavior
is unverified. Older firmware may send taps only. Game-specific and hold-to-use
behavior must be tested against the player's bindings. No physical-device or
game compatibility testing has been performed.
