# Home-screen construction intro

The updated original prompt and project requirements are in [docs/multi-cursor-intro-prompt.md](../../docs/multi-cursor-intro-prompt.md).

This is scripted decoration, not AI editing the user's configuration. The real editor stays mounted and runs normally. Four cursors first draw and reveal the real workspace and panel frames, then build the *actual visible controls* in place: the navigation, layers, macropad chassis, screen, knob, individual switches, quick assignments, control dock and inspector. The navigation and layers cursors exchange the header and sidebar: each draws a frame that the other fills. Visible sidebar and inspector labels, values and descriptions are revealed character by character, including wrapped lines, as the cursor moves across them. The text itself is never edited. No fake UI is substituted and no real actions are triggered. Elements below the viewport remain available when the user scrolls after the intro.

- Disable with `ENABLE_INTRO` in `config.ts`.
- Release builds play once per `sessionStorage` session; the development preview plays again on refresh. Replay from **Help & About → Replay intro**, or in development use **Ctrl+Alt+I**.
- Escape, Skip, or hold for 650 ms and release to skip. The release is captured so it cannot activate an underlying switch. Reduced motion bypasses the sequence.
- `REGION_SCRIPTS` lists real selectors and timings. Each selector can match multiple nodes; `stagger` places them individually; use `type` on text-only elements, or `textLeaves` on a container, to reveal its text without changing the DOM. Text bounds are measured on startup and resize so wrapped lines are typed in reading order. The engine measures visible bounds once, and again on resize/font readiness. Add a selector/timing to an existing track to animate another real element.
- `timeline.ts` runs four independent cursor tracks against one RAF master clock. The Controls track has its own modest speed adjustment; the other tracks retain their original timing. Each cursor glides away and fades once its own last element is placed, without waiting for the other tracks; the sequence ends when the last visible track has departed. The only overlays are cursors, temporary selection guides and skip controls. Each target's original inline opacity, translate, clip-path and transition values are restored. No elements are moved in layout or unmounted.
- `Intro.tsx` owns focus/inert state, timers, listeners and RAF, and cleans up on skip, completion, errors or unmount. A watchdog fails open if frames stop. `IntroBoundary` isolates render errors from the editor.
